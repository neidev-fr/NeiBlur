# NeiBlur
Première version de NeiBlur, par neidev. Ajoute du motion blur à tes vidéos glisse-les, choisis un style, lance le rendu. 6 préréglages, aperçu avant/après, file d'attente. Même moteur que Blur, mêmes performances. Lance NeiBlur.exe : le moteur (~116 Mo) s'installe seul au 1er démarrage. Windows 10/11 64 bits. Basé sur Blur (f0e), GPL-3.0.
